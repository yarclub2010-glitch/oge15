# Робот — тренажёр задания 15 ОГЭ

Веб-версия исполнителя Робот из системы Кумир для подготовки к заданию 15 ОГЭ
по информатике. Работает в браузере, установка не нужна.

**Открыть:** https://yarclub2010-glitch.github.io/story/

## Возможности

- **Язык Кумира:** `нц пока`, `нц N раз`, `нц для`, `кц при`, `если … то … иначе … все`,
  `выбор`, величины и таблицы, `вывод`, свои алгоритмы и функции.
- **Как в Кумире:** значения на полях справа от программы, пошаговое выполнение,
  клавиши F9 / F8 / Esc, красный угол ромбика при отказе Робота, пульт.
- **Библиотека заданий:** 14 заданий от разминки до сложных, в том числе форматы ОГЭ-2025.
- **Автоматическая проверка:** программа запускается на 30 вариантах бесконечного поля
  (как на рисунке, крайние размеры, случайные, длинные стены) и получает 0, 1 или 2 балла по критериям ОГЭ.
- **Свободное поле:** своя обстановка, стены и закраска мышью или пальцем,
  файлы `.fil`, совместимые с Кумиром.
- Подсказки при ошибках, подсказка и решение к каждому заданию, тёмная тема,
  телефон и планшет. Программы сохраняются в браузере.

Ссылку на конкретное задание можно отправить ученикам: например,
https://yarclub2010-glitch.github.io/story/#oge-2518 или `#sandbox` для свободного поля.

## Структура проекта

```
index.html            — страница тренажёра
src/
  main.js             — связывает всё вместе: запуск, проверка, режимы
  style.css           — оформление
  kumir/              — язык: lexer.js (слова), parser.js (разбор), interpreter.js (выполнение)
  robot/              — поле Робота: field.js (модель, файлы .fil), view.js (отрисовка, редактор)
  tasks/              — задания: tasks.js (библиотека и генераторы), checker.js (проверка, баллы)
  ui/editor.js        — редактор кода
tests/                — автотесты (открыть tests/index.html через локальный сервер)
docs/                 — разбор Кумира: сильные и слабые стороны
```

## Как добавить задание

В `src/tasks/tasks.js` добавьте объект в массив `TASKS`: `id`, `level` (1–4), `title`,
`text`, `hint`, функцию `generate(pick)`, которая строит поле и возвращает
`{ field, target }` (`target` — множество клеток `"x,y"`, которые нужно закрасить),
и эталонное решение `solution`. Автотесты сами проверят, что решение получает
2 балла на всех вариантах.

## Запуск на компьютере для разработки

Дважды щёлкните `start-server.bat` (нужен Python) — откроется http://localhost:8000.
Отправить изменения на GitHub — `sync.bat`.
