# Story

Браузерная игра на HTML/JS.

## Структура проекта

```
index.html              — точка входа (будет добавлена)
src/                    — исходный код игры
  scenes/               — сцены: меню, уровни, экраны
  entities/             — игровые объекты: игрок, NPC, предметы
  systems/              — механики: ввод, физика, сохранения, звук
  ui/                   — интерфейс: HUD, окна, диалоги
  utils/                — вспомогательные функции
assets/                 — ресурсы
  images/sprites/       — спрайты персонажей и объектов
  images/backgrounds/   — фоны
  images/ui/            — иконки и элементы интерфейса
  audio/music/          — музыка
  audio/sfx/            — звуковые эффекты
  fonts/                — шрифты
data/                   — игровые данные (JSON)
  levels/               — описания уровней
  dialogues/            — тексты и диалоги
docs/                   — дизайн-документ, заметки, идеи
```
